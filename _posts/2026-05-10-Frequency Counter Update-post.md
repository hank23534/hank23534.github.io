Frequency Counter Goals and Progress,

   The goal of this project is to make a home brew frequency counter capable of 9+ digits of accuracy and a default frequency range of 100 mhz - 100 Mhz. For the basic counter circuitry I am employing a SN74LV8154N as the primary work horse of this counter. The SN74LV8154N is capable of counting up to 4,294,967,296 (32 bits) before overflowing. A second SN74LV8154N is also used as a software controllable pre-scaler so the STM32 can address the GAL, GAU, GBL, and GBU pins to choose between 1/2, 1/512, 1/131072, and 1/33554432 dividers, This is how the counter is able to achieve 9+ digit accuracy without directly increasing the sample period. The counting method used by this counter is a modified version of the Reciprocal Counting Method common in many high quality counter. effectively how the Reciprocal Counting Method works is by allowing clock pulses (in this case of 10MHZ) to be counted for the period of the input signal. Thus this method can achieve very high accuracy with frequencies 10x or more smaller than that of the clock signal. essentially the lower the input frequency the higher the accuracy. This is why I have employed the second SN74LV8154N as a pre-scaler or divider of the input signal. while a 1/33554432 pre-scale value may seem extreme at first glance doing the math for a 100Mhz input and a 10Mhz clock yields that the pre-scaled frequency will be ~2.98hz and thus 3,355,443 pulses will be counter which is still far below the maximum count for the counter. having such a large pre-scaler necessitates that the counter needs to [synchronous](https://www.allaboutcircuits.com/textbook/digital/chpt-11/synchronous-counters/) to avoid drift or any inaccuracies. This is a general overview of the counting method which I will be using in my latest home brew test equipment project further updates on this project are sure to come as I have a back log of info that needs to be added to GitHub (Schematics, ECad, ETC). As of 5/10/26 I Have finished breadboard prototyping and have finished the first prototype pcb board for the counter, as well as most of the C programming for the STM32C051C6T6. I plan to write up a few more post about other sections of the counter circuity (Oven Oscillator, Counter Latch, PSU, ETC) while I'm waiting for the PCB boards.
