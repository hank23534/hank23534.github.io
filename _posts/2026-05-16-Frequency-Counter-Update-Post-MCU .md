  In this update I'll discuss the MCU that I selected for the counter, the STM32C051C6T6 and its accompanying program. This MCU is apart of ST's new lineup of low power low cost MCUs with the 
  designated purpose to help phase out and replace older 8 and 16 bit MCUs and other low power line ups like AVR and PIC. The MCU retails on Mouser for 99 cents for 
  orders over ten units. Thus this MCU was a great choice for this project not only did it help in building my familiarity with the newer instruction set and registers,
  but will also help with keeping future projects using powerful 32 bit ARM MCUs instead of older 8 bit AVR MCUs (which are three times the cost). Most of the initialization 
  code, things like GPIO registers, debug interfaces, and other boring task were generated by ST's MXCUBE software. After the basic program files where generated I created 
  the application ecosystem and began writing the main program. I used Vs-code’s STM32 extension to upload and debug the MCU, I am aware of the STM32IDE however I don't think 
  it really has much to offer. I have tried to keep the program as small and easy to understand as possible, and have tried to use the smallest number of timers and other
  peripherals to allow for future expand-ability. The bulk of the C program file is mainly IO encoding for controlling the VFD and counter byte select pins. I'm still debugging
  cleaning up the program but once I'm done I will upload the whole project folder onto the GitHub page for everyone.
